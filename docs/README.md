# Library Management System — Documentation Set

This folder contains the product requirements, software requirements, and technical design for the Library Management System.

| File | Purpose |
|---|---|
| [PRD.md](PRD.md) | Product purpose, users, features, scope, priorities, user stories, and release plan |
| [SRS.md](SRS.md) | Functional/non-functional requirements, role permissions, workflows, acceptance criteria, and traceability |
| [TDD.md](TDD.md) | Architecture, diagrams, data model, APIs, security, tests, deployment, and future payment design |

## Release summary

- **MVP — Midterm:** Core catalogue, copies, members, issue/return, due dates, and overdue records.
- **Beta — Final:** Authentication, Member/Librarian/Admin permissions, borrowing requests, dashboards, and production hardening.
- **Future Phase:** Optional library fines and hosted payment integration. Payment processing is not part of MVP or Beta.

These documents describe intended scope and design; a listed feature is not considered implemented until code and tests confirm it.
